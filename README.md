# Smart Task Tracker

Первая MVP-версия статического веб-приложения для проверки цепочки GitHub Pages → Firebase Authentication → Cloud Firestore.

## Возможности

- вход по email и паролю через Firebase Authentication;
- загрузка профиля из `users/{uid}`;
- загрузка проектов из `users/{uid}/projects`;
- загрузка задач из `users/{uid}/tasks`;
- сопоставление задачи с названием проекта;
- выход из аккаунта;
- понятные сообщения об ошибках и пустом списке задач.
- создание, редактирование и удаление задач;
- отметка задач выполненными;
- создание проектов;
- месячный календарь с переключением месяцев;
- поиск и фильтрация задач;
- автоматическое обновление данных через Firestore realtime listeners.
- установка на компьютер как PWA-приложения;
- безопасная смена email и пароля через Firebase Authentication.

UID нигде не задан вручную: после входа приложение использует `user.uid`.

## Локальный запуск

ES-модули нельзя надёжно запускать простым открытием `index.html` с диска. Запустите любой статический HTTP-сервер из папки проекта, например средствами VS Code (Live Server), затем откройте выданный локальный адрес.

С Python, если он уже установлен:

```powershell
python -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Публикация на GitHub Pages

1. Загрузите файлы в GitHub-репозиторий.
2. В `Settings → Pages` выберите публикацию из ветки (`Deploy from a branch`).
3. Выберите нужную ветку и папку `/ (root)`.
4. Добавьте домен GitHub Pages в Firebase Console: `Authentication → Settings → Authorized domains`.

Firebase Web API key находится в клиентской конфигурации штатно и не является паролем. Пароли пользователей приложение не сохраняет.
